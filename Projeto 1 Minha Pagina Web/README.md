---

## Descrição do trabalho

Site pessoal desenvolvido como projeto da disciplina de Desenvolvimento Front-End para Web.
O objetivo foi apresentar minha trajetória, interesses e objetivos utilizando HTML semântico e CSS básico.

---

## Como abrir as páginas

1. Baixe (ou extraia) todos os arquivos na mesma pasta
2. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge)
3. Use o menu de navegação para ir até a página de **Contato** (`contato.html`)
4. Na página de Contato, use o link do rodapé para voltar à página principal

> Não é necessário servidor local – os arquivos funcionam diretamente no navegador.

---

## Estrutura de arquivos

```
projeto/
├── index.html      → Página principal
├── contato.html    → Página complementar (formulário de contato)
├── style.css       → Estilos básicos compartilhados pelas duas páginas
├── foto.jpg        → (opcional) Substitua pela sua foto pessoal
└── README.md       → Este arquivo
```
